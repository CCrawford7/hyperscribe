# Hyperscribe v1.2.0 Planned Features

## Ready to Implement

### Drag to reorder tabs
- Pure JS/CSS, no dependencies
- Use HTML5 drag-and-drop API on tab elements
- Visual feedback during drag (placeholder, opacity)
- Persist order in state

### Right-click context menu
- Extends existing spellcheck context menu pattern
- Cut/Copy/Paste/Select All
- Insert timestamp, Insert template
- Clear formatting (if we add rich text later)

### Note search
- Search input in a new panel or modal
- Highlight matching tabs, show preview snippets
- Click result to switch to that tab and scroll to match

## Medium Effort

### Undo/redo history
- Snapshot-based or diff-based history
- Visual timeline/list UI
- Storage considerations (limit history depth)

### Voice notes (Speech-to-text)
- Web Speech API
- Browser support: Chrome/Edge excellent, Firefox limited
- Microphone permission required
- Toggle button to start/stop dictation
- Insert transcribed text at cursor

## Larger Scope

### Code block formatting
- Requires syntax highlighting library (Prism.js ~20KB or Highlight.js ~40KB)
- Options: highlight in-place or markdown-style fenced blocks
- Consider: may conflict with plain-text philosophy
